使用说明

🎯 定时消息：选择发送机器人 → 输入消息内容 → 设置执行时间和重复规则（每天/工作日/每周）→ 可选 @所有人 → 点击添加。任务列表中通过开关控制启停，支持删除。

📢 值班消息：选择发送机器人 + 值班信息表 + 可选附加消息 + @所有人 → 点击「立即发送」推送。可通过「+ 添加任务」创建定时值班通知。

💬 消息流：以工作流方式编排复杂消息。添加「自定义文本」「数据处理结果」「发送消息」等步骤，串行拼接后一键发送。支持预览消息内容、保存消息流，下次加载后可更换文件复用。

📊 数据处理：上传 Excel 文件 → 选择文件 → 编排数据处理步骤（分类筛选、文本/数值/日期/行列操作等）→ 执行后在弹窗中预览结果。支持保存数据流并复用。

⚙️ 功能配置：管理钉钉 Webhook 机器人（切换外网/内网、输入 Access Token 和加签 Secret，支持编辑删除）和上传 Excel 文件。

📨 发送日志：统一查看所有发送记录，按时间倒序排列，用彩色标签区分「值班消息」和「消息流」来源，支持清空全部日志。

📝 调试日志：查看后端运行日志，支持自动刷新和导出 TXT 文件。

🖥️ 系统托盘：关闭窗口后应用托盘常驻，定时任务持续运行。右键托盘图标可重新打开窗口或退出应用。侧边栏底部可折叠/展开。
