# 🤖 值班机器人管理平台

钉钉自定义机器人值班通知桌面管理工具，支持多机器人配置、值班表上传解析、定时/手动消息发送、加签安全验证。

---

## 功能概览

| 模块 | 说明 |
|------|------|
| **值班机器人通知** | 多选机器人 + 选择值班表 + @所有人，定时或手动发送 Markdown 格式值班信息 |
| **自定义消息通知** | 多选机器人 + 自由编辑消息内容，支持定时发送 |
| **值班信息表管理** | 上传 `.xlsx` 文件 → 自动解析预览 → 保存到本地数据库 |
| **机器人配置管理** | 钉钉机器人 Webhook 的**增删改查**，支持加签 Secret 配置 |
| **发送日志** | 记录每次发送的时间、目标机器人、内容摘要、成功/失败状态 |
| **定时任务调度** | 基于 APScheduler，支持每天/工作日/每周 cron 规则，调度状态实时显示 |
| **调试日志** | 实时查看后端运行日志，支持自动刷新和导出 TXT 文件 |

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | HTML/CSS/JS（单文件）+ SheetJS（xlsx 解析） |
| 桌面壳 | [Eel](https://github.com/python-eel/Eel)（Python ↔ JS WebSocket 桥接） |
| 后端 | Python 3.10+ |
| 定时调度 | APScheduler |
| 数据库 | SQLite（`~/.dutybot/dutybot.db`） |
| 消息推送 | 钉钉自定义机器人 Webhook（Markdown 格式 + 加签） |
| 打包 | PyInstaller（可选） |
| HTTP 服务 | Flask（可选，默认关闭） |

## 快速开始

### 1. 环境要求

- Python 3.10+
- Chrome 或 Chromium 浏览器（Eel 桌面窗口依赖）

### 2. 安装依赖

```bash
cd dutyBot
pip install -r requirements.txt
```

### 3. 启动应用

```bash
python main.py
```

应用会自动打开一个桌面窗口，加载管理界面。

### 4. 打包为独立应用（可选）

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name dutyBot --add-data "web:web" main.py
```

## 使用指南

### 配置机器人

1. 点击左侧 **「机器人配置」**
2. 点击 **「+ 添加机器人」**，填写：
   - **名称**：任意标识，如 "技术值班机器人"
   - **Webhook 地址**：钉钉群机器人的 Webhook URL（`https://oapi.dingtalk.com/robot/send?access_token=...`）
   - **加签 Secret**：钉钉机器人安全设置 → 加签 → 复制 SEC 密钥
3. 点击确认即可添加
4. 支持 **✏️ 编辑** 修改已有机器人配置

> 如何获取 Webhook 地址？
> 钉钉 PC 端 → 群设置 → 智能群助手 → 添加机器人 → 自定义（通过 Webhook 接入）→ 复制 Webhook 地址
> 如需签名校验，在安全设置中勾选"加签"，复制 SEC 密钥填入 Secret 字段

### 上传值班表

1. 点击左侧 **「值班信息表」**
2. 选择 `.xlsx` 文件（格式：第一列日期、第二列星期、第三列值班人员）
3. 点击 **「📋 解析预览」** 查看数据
4. 确认无误后点击 **「☁️ 上传保存」**
5. 已上传的值班文件在下方列表中可预览或删除

### 发送值班通知

1. 点击左侧 **「值班机器人通知」**
2. 勾选目标机器人（可多选）
3. 选择已上传的值班表
4. 可选开启 @所有人
5. 点击 **「📤 单次发送测试」** 立即发送

### 设置定时任务

1. 在 **值班机器人通知** 或 **自定义消息通知** 面板中
2. 点击 **「+ 添加任务」**
3. 在弹窗中设置执行时间和重复规则（📅 每天 / 💼 工作日 / 📆 每周）
4. 确认后任务自动生效，**调度状态按钮** 会变为绿色 🟢 调度运行中

### 查看运行日志

1. 点击左侧 **「调试日志」**
2. 查看深色终端风格的后端运行日志
3. **🔄 刷新**：手动拉取最新日志
4. **⏯ 自动刷新**：每 3 秒自动更新
5. **📥 导出 TXT**：下载完整日志文件
6. **清空显示**：清除当前查看内容（不影响日志文件）

## 常见问题

**Q: 启动后没有弹出窗口？**
A: 确保系统安装了 Chrome 或 Chromium 浏览器。Eel 默认使用 `mode='chrome'`。

**Q: 发送消息返回"签名不匹配"错误？**
A: 钉钉机器人开启了加签安全设置。请在机器人配置中填写正确的 **加签 Secret** 密钥（SEC 开头的一串字符），程序会自动计算签名。

**Q: 定时任务没有按时执行？**
A: 确保应用保持运行状态（窗口打开）。检查调度状态按钮是否为绿色 🟢，灰色 ⏸ 表示无启用任务。

**Q: 定时任务创建后按钮显示灰色？**
A: 检查任务右侧的开关是否为开启状态。只有开关开启的任务才会被调度执行。

**Q: 数据库在哪里？如何备份？**
A: 数据库位于 `~/.dutybot/dutybot.db`，直接复制该文件即可备份。删除该文件可重置所有数据。
