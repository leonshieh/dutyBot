# 🤖 值班机器人管理平台

钉钉自定义机器人值班通知桌面管理工具，支持外网/内网双模式、多机器人配置、值班表上传解析、定时/手动消息发送、加签安全验证、系统托盘常驻。

---

## 功能概览

| 模块 | 说明 |
|------|------|
| **值班机器人通知** | 多选机器人 + 选择值班表 + @所有人，今日值班 + 下次预告双段式消息 |
| **自定义消息通知** | 多选机器人 + 自由编辑消息内容，支持全选/反选/取消 |
| **值班信息表管理** | 上传 `.xlsx` → 自动解析预览（yyyy/mm/dd）→ 保存到本地数据库 |
| **机器人配置管理** | 外网/内网切换 + Access Token 输入 + 加签 Secret，自动拼装完整 Webhook |
| **发送日志** | 记录发送时间、目标、内容、状态，支持刷新和清空 |
| **定时任务调度** | APScheduler cron 规则，任务摘要彩色标签展示，一键启停全部任务 |
| **调试日志** | 深色终端风格实时日志，自动刷新 + 导出 TXT |
| **系统托盘** | 关闭窗口后托盘常驻，定时任务持续运行，托盘菜单退出 |

---

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | HTML/CSS/JS（单文件）+ SheetJS（本地 xlsx 解析） |
| 桌面壳 | [Eel](https://github.com/python-eel/Eel)（Python ↔ JS WebSocket 桥接） |
| 托盘 | pystray + Pillow（系统托盘常驻） |
| 后端 | Python 3.10+ |
| 定时调度 | APScheduler |
| 数据库 | SQLite（`~/.dutybot/dutybot.db`） |
| 消息推送 | 钉钉自定义机器人 Webhook（Markdown + 加签，兼容内外网） |
| 打包 | PyInstaller |

## 快速开始

### 1. 环境要求

- Python 3.10+
- Chrome 或 Chromium 浏览器（Eel 桌面窗口依赖）

### 2. 安装依赖

```bash
cd dutyBot
pip install -r requirements.txt
```

### 3. 启动应用

```bash
python main.py
```

应用自动打开桌面窗口，同时系统托盘出现蓝色图标。**关闭窗口后应用不会退出**，定时任务持续运行。通过托盘菜单「退出应用」彻底停止。

## 使用指南

### 配置机器人

1. 点击左侧 **「功能配置」→「机器人配置」**
2. 点击 **「+ 添加机器人」**，填写：
   - **名称**：如 "技术值班机器人"
   - **Webhook类型**：切换外网/内网模式
   - **Access Token**：粘贴钉钉机器人的 token（无需输入完整地址）
   - **加签 Secret**：钉钉安全设置 → 加签 → 复制 SEC 密钥
3. 支持 **编辑** 修改已有配置

> 外网地址：`https://oapi.dingtalk.com/robot/send?access_token=`
> 内网地址：`https://openplatform-pc-pro.dingding.bankcomm.com/robot/send?access_token=`

### 上传值班表

1. 点击 **「功能配置」→「值班信息表」**
2. 选择 `.xlsx` 文件（格式：第一列日期、第二列星期、第三列值班人员）
3. 点击 **「解析预览」** 查看数据（日期自动转为 yyyy/mm/dd）
4. 确认后点击 **「上传保存」**

### 发送值班通知

1. 点击 **「值班消息」**
2. 勾选目标机器人（支持全选/反选/取消）
3. 选择值班信息表
4. 可选开启 @所有人
5. 点击 **「立即发送」**

发送的消息格式自动包含今日值班信息和下次值班预告。

### 设置定时任务

1. 点击 **「+ 添加任务」**
2. 选择机器人、发送内容、@所有人开关
3. 设置执行时间和重复规则（每天/工作日/每周）
4. 任务列表彩色标签展示：规则+时间（蓝）、机器人（紫）、内容（绿）、@所有人（橙）
5. 调度状态按钮一键启停全部任务

### 系统托盘

- **关闭窗口**：窗口隐藏，托盘图标保持，定时任务继续运行
- **退出应用**：右键托盘图标 → 退出应用

## 常见问题

**Q: 关闭窗口后定时任务还会运行吗？**
A: 会。关闭窗口后应用进入托盘常驻模式，调度器继续运行。彻底退出需右键托盘图标 → 退出应用。

**Q: 发送消息返回"签名不匹配"？**
A: 钉钉机器人开启了加签。请在配置中填写正确的 **加签 Secret** 密钥。

**Q: 如何切换内外网？**
A: 添加/编辑机器人时切换 Webhook 类型的滑块开关即可，系统自动拼装完整地址。

**Q: 上传值班表日期显示不正确？**
A: 系统自动将 Excel 日期转为 `yyyy/mm/dd` 格式，支持序列号和字符串两种来源。

**Q: 数据库在哪里？如何备份？**
A: 数据库位于 `~/.dutybot/dutybot.db`，复制该文件即可备份，删除可重置所有数据。
